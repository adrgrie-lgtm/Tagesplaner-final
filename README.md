# Familien-Tagesplaner (PWA)

Dieses Repository enthält die ausgelieferte Web-App des Familien-Tagesplaners als Progressive Web App:

- Live-Build unter `docs/` (HTML, Manifest, Service Worker, Icons)
- Installierbar als App, mit Offline-Cache
- Gemeinsame Termine und Aufgaben für die Familie

## Struktur

- `docs/` – ausgelieferte PWA
- `.github/` – Workflows
